# グラウンド・オートバトラー 正式仕様書 - 01: ゲーム概要・カード仕様

---

## 1. ゲーム概要

* **ゲーム名**: グラウンド・オートバトラー
* **プレイ人数**: 2～10人
* **初期ライフ**: 各プレイヤー **5**
  * 表示形式: 生存時 `♥♥♥♥♥`（最大5）、脱落時 `♡♡♡♡♡`
  * バトル敗北ごとにライフが 1 減少する（`♥♥♥♥♥` → `♥♥♥♥♡`）。
* **初期ゴールド**: 各プレイヤー **20G**
  * 各ラウンドの準備フェーズ開始時に以下のゴールドが付与される（ラウンド1は付与なし）。
    * **ラウンド2～4**: **+10G**
    * **ラウンド5以降**: **+15G**
* **ゲームの進行**:
  準備フェーズ（購入・合成・配置・解雇）とバトルフェーズ（自動戦闘）を交互に繰り返す。
  ライフが 0 になったプレイヤーは脱落し、最後の1人（または同時脱落者全員）が優勝となる。

## 2. カード基本仕様

### 2.1. 基本スタッツとランダム配分
各カードは **HP**・**攻撃 (ATK)**・**素早さ (SPD)** の3スタッツを持つ。
カードがショップに陳列される際、レアリティごとに定められた「合計スタッツ」が、**各レアリティの最低値を下回らないように**各スタッツに整数値でランダムに配分される。
* 各スタッツの最低値はレアリティごとに規定される（次項2.2参照）。
* 3スタッツの合計は、各レアリティの合計スタッツと常に一致する。

### 2.2. レアリティ設定

| レアリティ | カード枠色 | 合計スタッツ | 各スタッツの最低値 | 通常購入額 |
| :--- | :--- | :---: | :---: | :---: |
| **コモン** | グレー (`#94a3b8`) | 10 | **1** | 2G |
| **アンコモン** | 緑 (`#22c55e`) | 20 | **2** | 4G |
| **レア** | 青 (`#38bdf8`) | 30 | **3** | 6G |
| **エピック** | 紫 (`#a855f7`) | 40 | **4** | 8G |
| **レジェンド** | 金 (`#facc15`) | 50 | **5** | 10G |

### 2.3. カードUIの行分割レイアウト
カードUIは視認性を最大限に確保するため、上部情報が2行に分割されて表示される。

1. **第1行（属性・種族行）**:
   * 属性バッジ（専用カラー）
   * 種族名（「リザードマン」等の長い名称も改行されず1行で表示）
2. **第2行（評価・購入額行）**:
   * **★バッジ**（カード評価指標）
   * **「解」バッジ**（解雇市場由来カードのみ、★バッジの右隣に配置）
   * **購入額**（通常ショップまたは解雇市場に陳列中のカードにのみ右端に表示。手札・出撃UI等では非表示）
3. **カード名エリア**:
   * 文字数に応じて自動的にフォントサイズが縮小され、枠外へのはみ出しを防止する。
4. **スタッツエリア**:
   * HP（❤）、攻撃（⚔）、素早さ（⚡）の記号と数値で構成。

## 3. カードバッジ仕様

### 3.1. 「★バッジ」（数値的評価指標）
カードの成長度・強さを示す指標。

* **初期値**: 新規生成されたカードの★バッジは一律 **「★1」** とする。
* **合成時の合算ルール**: カード合成が行われた際、合成元カードの★数値と素材カードの★数値を合計した値が、合成後カードの★数値となる。
  * 例: ★1 ＋ ★1 ＝ **★2**
  * 例: ★1 ＋ ★2 ＝ **★3**
  * 例: ★4 ＋ ★3 ＝ **★7**
* **解雇市場での引き継ぎ**: カードが解雇され解雇市場に陳列された場合、解雇時点の★バッジ数値をそのまま引き継ぐ（「★1」へ初期化されない）。

### 3.2. 「解バッジ」（解雇市場由来カード）
解雇市場から購入したカードに付与されるバッジ。カード上部第2行の「★バッジ」のすぐ右隣に配置される。

* **外観**: 落ち着いた彩度低めのダークグレー（`#334155`）背景に白い文字。
* **吹き出し型ポップアップ**:
  * 「解」バッジにマウスオーバーした際のみ、上部に吹き出し型のポップアップで **「解雇者：〇〇」** が表示される。カード本体のホバーでは表示されない。
* **解雇（売却）時の獲得ゴールド**:
  * 「解バッジ」が付与されたカードを解雇した場合、獲得ゴールドは以下の計算式に従う（合計スタッツは使用しない）。

$$
\text{獲得ゴールド} = \left\lfloor \frac{\text{ショップでの購入額} \times \text{★バッジの数値}}{4} \right\rfloor
$$

* **合成時の扱い**:
  * 合成元または素材に「解バッジ」が付与されていても、**合成後のカードには「解バッジ」を引き継がない**（通常のカードとなる）。

## 4. 属性相性とカラー

### 4.1. 属性カラー一覧
* **火**：赤 (`#ef4444`)
* **氷**：水色 (`#38bdf8`)
* **風**：緑 (`#22c55e`)
* **雷**：紫 (`#a855f7`)
* **水**：青 (`#3b82f6`)
* **地**：黄色 (`#eab308`)

### 4.2. 属性相性サイクル
属性は以下の2つの独立した3すくみサイクルを構成する。

* **相性サイクル 1**: 火 ➔ 氷 ➔ 風 ➔ 火（火は氷に強く、氷は風に強く、風は火に強い）
* **相性サイクル 2**: 雷 ➔ 水 ➔ 地 ➔ 雷（雷は水に強く、水は地に強く、地は雷に強い）

### 4.3. ダメージ倍率
* **弱点属性への攻撃**: 与えるダメージが **2.0倍**
* **耐性属性への攻撃**: 与えるダメージが **0.5倍**（半減）
* **等倍属性への攻撃**: 与えるダメージが **1.0倍**

## 5. 種族倍率補正

### 5.1. 適用ルールと計算対象の完全分離
各プレイヤー自身の所持カード（手札＋出撃スロット）の中に**同じ種族のカードが2枚以上**ある場合、同種族のカードへスタッツ補正を適用する。

* **計算対象の分離**: 自分自身のカードのみを集計対象とし、**相手プレイヤーの同種族カードと合算して計算することは絶対にない**。
* **常時適用の原則**: 準備フェーズ中も含め、所持条件を満たしている限り常に補正後のスタッツが反映される。
* **適用対象カードUIの限定**:
  1. 自分の手札UI
  2. 自分の繰り出しUI
  3. バトルフェーズ中の自分の戦闘カードUI
  4. バトルリザルト画面の自分のカードUI
  * ※ショップや解雇市場のカードには種族倍率補正を適用しない。

### 5.2. 補正対象スタッツの表示色規約
* 種族倍率補正が適用されているスタッツは、**数値部分のみを緑色 (`#22c55e`)** で表示する。
* 数値の左隣にある記号（HP: ❤、攻撃: ⚔、素早さ: ⚡）の色は従来の固有カラーを厳格に維持し、緑色に変更しない。
* 補正対象外のスタッツは、従来の白色数値を維持する。
* ※相手の戦闘カードUIや「前ラウンド情報」モーダル内の相手カードにおいても、相手自身の構成に基づく補正スタッツの**数値部分のみ**が同様に緑色で表示される。

### 5.3. 種族別補正倍率一覧
* 同種族カード枚数を $N$ とする。
* 端数処理: 計算値は**小数点以下四捨五入**。

| 種族 | 補正対象スタッツ | 補正倍率の計算式 |
| :--- | :--- | :--- |
| **ドワーフ** | HP | $1 + (N - 1) \times 0.10$ |
| **ドラゴン** | 攻撃 | $1 + (N - 1) \times 0.10$ |
| **エルフ** | 素早さ | $1 + (N - 1) \times 0.10$ |
| **オーク** | HP・攻撃 | $1 + (N - 1) \times 0.05$ |
| **ヴァンパイア** | HP・素早さ | $1 + (N - 1) \times 0.05$ |
| **リザードマン** | 攻撃・素早さ | $1 + (N - 1) \times 0.05$ |
