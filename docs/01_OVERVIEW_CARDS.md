# グラウンド・オートバトラー 正式仕様書 - 01: ゲーム概要・カード仕様

---

## 1. ゲーム概要

* **ゲーム名**: グラウンド・オートバトラー
* **プレイ人数**: 2～10人
* **初期ライフ**: 各プレイヤー **5**
  * 表示形式: 生存時 `♥♥♥♥♥`（最大5）、脱落時 `♡♡♡♡♡`
  * バトル敗北ごとにライフが 1 減少する（`♥♥♥♥♥` → `♥♥♥♥♡`）。
* **初期ゴールド**: 各プレイヤー **20G**
  * 各ラウンドの準備フェーズ開始時に以下のゴールドが付与される（ラウンド1は付与なし）。
    * **ラウンド2～4**: **+10G**
    * **ラウンド5以降**: **+15G**
* **ゲームの進行**:
  準備フェーズ（購入・合成・配置・解雇）とバトルフェーズ（自動戦闘）を交互に繰り返す。
  ライフが 0 になったプレイヤーは脱落し、最後の1人（または同時脱落者全員）が優勝となる。

## 2. カード基本仕様

### 2.1. 基本スタッツとランダム配分
各カードは **HP**・**攻撃 (ATK)**・**素早さ (SPD)** の3スタッツを持つ。
カードがショップに陳列される際、レアリティごとに定められた「合計スタッツ」が、**各レアリティの最低値を下回らないように**各スタッツに整数値でランダムに配分される。
* 各スタッツの最低値はレアリティごとに規定される（次項2.2参照）。
* 3スタッツの合計は、各レアリティの合計スタッツと常に一致する。

### 2.2. レアリティ設定

| レアリティ | カード枠色 | 合計スタッツ | 各スタッツの最低値 | 通常購入額 |
| :--- | :--- | :---: | :---: | :---: |
| **コモン** | グレー (`#94a3b8`) | 10 | **1** | 2G |
| **アンコモン** | 緑 (`#22c55e`) | 20 | **2** | 4G |
| **レア** | 青 (`#38bdf8`) | 30 | **3** | 6G |
| **エピック** | 紫 (`#a855f7`) | 40 | **4** | 8G |
| **レジェンド** | 金 (`#facc15`) | 50 | **5** | 10G |

### 2.3. 最新カードUIのレイアウト構造（ピクセルパーフェクト・日英3:2独立リサイズ表示）
カードUIは高い視認性とイラスト演出を両立した、以下の縦型レイアウト（外寸 124px × 178px、ボーダー 2px）で構成される。

1. **最上部ヘッダー部**:
   * **左上**: 属性を示す円形シンボルアイコン（火・氷・風・雷・水・地）。左上に絶対配置され、カード枠から美しく浮き出るデザイン。
   * **種族名配置**: カード全幅に対する中央揃えで配置。長い名称であっても文字サイズが自動調整（`.race-long`, `.race-very-long`）され、枠内に美しく収まる。
2. **カードイラストエリア（完全整数 120px × 90px・2:1高精細スケーリング）**:
   * **完全整数ピクセル描画**: イラスト枠の内寸は **幅120px × 高さ90px**（縦横比 4:3）に完全固定される。
   * **2:1完全倍率スケーリング**: 元画像アセット（240px × 180px）に対して完全な「2:1（正確に半分）」の整数比率でピクセルグリッドに吸着させて描画する。
   * **クリーン構造**: 上下の余計なボーダー線（`border-top`, `border-bottom`）は一切排除し、純粋な画像領域を維持する。
   * **GPUテクスチャ保護**: `contain: paint;` を指定し、親要素のグラスモフィズム（`backdrop-filter`）によるテクスチャ解像度の間引きからイラスト描画を独立保護する。
   * **画像無限読み込み安全遮断規約**: 読み込みエラー時のフォールバック処理は、必ず `this.onerror = null;` を設定してエラーイベントの無限再発火を遮断する。画像読み込み失敗時は属性アイコンによるフォールバック背景が表示される。
   * **ドラッグ操作仕様**:
     ブラウザ標準の画像ドラッグ機能は完全に阻止（`-webkit-user-drag: none; pointer-events: none;`）する。**カードイラスト部分（`.card-art-container`）をドラッグした場合でも、通常どおりカードUI全体のカスタムドラッグが発火し、自由に移動・配置できる**。
   * **★バッジ（重ね表示）**: イラスト画像エリアの**上部左側**にピル型バッジとしてオーバーレイ配置。
   * **「解」バッジ（重ね表示）**: 解雇市場由来カードのみ、イラスト画像エリアの**下部右側**にピル型バッジとしてオーバーレイ配置。
3. **カード名プレート（日本語・英語の2行分離・比率3:2・独立自動リサイズ表示）**:
   * イラスト画像直下に配置（高さ32px）。
   * **1行目**: 日本語のカード名（太字、白文字、中央揃え）
   * **2行目**: 英語のカード名（括弧「()」は完全除去、グレー文字、中央揃え）
   * **文字サイズ比率**: **日本語：英語 ＝ 3：2**（基本フォントサイズ: 日本語 `0.69rem` / 英語 `0.46rem`）を厳格に維持。
   * **通常時のサイズ一定化原則**:
     名前の長さに関わらず、通常時（日本語11文字以下、英語24文字以下）は常に上記基本フォントサイズで一定に表示され、短い名前が不当に縮小されることはない。
   * **本来の英語大文字・小文字表記維持**:
     英語表記について大文字強制（`text-transform: uppercase`）は一切行わず、**カードマスタ定義の大文字・小文字表記（例: `Flame Hatchling`）をそのまま忠実に表示**する。
   * **日英独立・はみ出し時のみの自動リサイズ**:
     カード枠（内幅116px）からはみ出しそうな長い名称に限り、日本語側（`.ja-long`, `.ja-very-long`, `.ja-ultra-long`）と英語側（`.en-long`, `.en-very-long`, `.en-ultra-long`）で**独立して個別にフォントサイズを縮小**する。片方の長さを理由にもう片方が巻き添えで縮小されることはなく、末尾の省略記号（「…」）を完全に排除して**名前全体（全文）が表示**される。
4. **最下部スタッツバー**:
   * HP（❤）、攻撃（⚔）、素早さ（⚡）の記号と数値を横並びで均等配置。
   * 種族倍率補正が適用されているスタッツは、**数値部分のみを緑色 (`#22c55e`)** で強調表示する。
5. **購入額の表示（ショップ・解雇市場）**:
   * **カードUI内部には配置せず**、ショップおよび解雇市場に陳列されている各カードの**直下（外側）に中央揃え**で、金貨アイコン付きピル型バッジ（`🟡 2G` 等）として美しく表示される。

## 3. カードバッジ仕様

### 3.1. 「★バッジ」（数値的評価指標）
カードの成長度・強さを示す指標。

* **初期値**: 新規生成されたカードの★バッジは一律 **「★1」** とする。
* **表示位置**: カードイラスト画像エリアの**上部左側**にオーバーレイ（重ねて）配置される。
* **合成時の合算ルール**: カード合成が行われた際、合成元カードの★数値と素材カードの★数値を合計した値が、合成後カードの★数値となる。
  * 例: ★1 ＋ ★1 ＝ **★2**
  * 例: ★1 ＋ ★2 ＝ **★3**
  * 例: ★4 ＋ ★3 ＝ **★7**
* **解雇市場での引き継ぎ**: カードが解雇され解雇市場に陳列された場合、解雇時点の★バッジ数値をそのまま引き継ぐ（「★1」へ初期化されない）。

### 3.2. 「解バッジ」（解雇市場由来カード）
解雇市場から購入したカードに付与されるバッジ。

* **外観**: 落ち着いたダークトーン背景（`#0f172a`）に白い文字で **「解」** と表示（「バッジ」の文字は含まない）。
* **表示位置**: カードイラスト画像エリアの**下部右側**にオーバーレイ（重ねて）配置される。
* **吹き出し型ポップアップ**:
  * 「解」バッジにマウスオーバーした際のみ、上部に吹き出し型のポップアップで **「解雇者：〇〇」** が表示される。カード本体のホバーでは表示されない。
* **解雇市場での購入価格**:
  * 解雇市場に陳列されるカードの購入価格は、以下の計算式に従う（カード直下に中央揃えで表示）。

$$
\text{解雇市場での購入価格} = \left\lfloor \frac{\text{ショップでの購入額} \times \text{★バッジの数値}}{2} \right\rfloor
$$

* **解雇（売却）時の獲得ゴールド**:
  * 「解バッジ」が付与されたカードを解雇した場合、獲得ゴールドは以下の計算式に従う。

$$
\text{獲得ゴールド} = \left\lfloor \frac{\text{ショップでの購入額} \times \text{★バッジの数値}}{4} \right\rfloor
$$

* **合成時の扱い**:
  * 合成元または素材に「解バッジ」が付与されていても、**合成後のカードには「解バッジ」を引き継がない**（通常のカードとなる）。

## 4. 属性相性とカラー

### 4.1. 属性カラーおよびシンボル
* **火**：鮮やかな紅炎色 (`#ef4444`) / 火炎シンボル
* **氷**：澄んだ氷青色 (`#38bdf8`) / 氷晶シンボル
* **風**：疾風の深緑色 (`#22c55e`) / 旋風シンボル
* **雷**：紫電の雷光色 (`#a855f7`) / 稲妻シンボル
* **水**：深海の青色 (`#3b82f6`) / 水滴シンボル
* **地**：大地の大地色 (`#eab308`) / 鉱石シンボル

### 4.2. 属性相性サイクル
属性は以下の2つの独立した3すくみサイクルを構成する。

* **相性サイクル 1**: 火 ➔ 氷 ➔ 風 ➔ 火（火は氷に強く、氷は風に強く、風は火に強い）
* **相性サイクル 2**: 雷 ➔ 水 ➔ 地 ➔ 雷（雷は水に強く、水は地に強く、地は雷に強い）

### 4.3. ダメージ倍率
* **弱点属性への攻撃**: 与えるダメージが **2.0倍**
* **耐性属性への攻撃**: 与えるダメージが **0.5倍**（半減）
* **等倍属性への攻撃**: 与えるダメージが **1.0倍**

## 5. 種族倍率補正

### 5.1. 適用ルールと計算対象の完全分離
各プレイヤー自身の所持カードの中に**同じ種族のカードが2枚以上**ある場合、同種族のカードへスタッツ補正を適用する。

* **計算対象の分離**: 自分自身のカードのみを集計対象とし、**相手プレイヤーの同種族カードと合算して計算することは絶対にない**。
* **常時適用の原則**: 準備フェーズ中も含め、所持条件を満たしている限り常に補正後のスタッツが反映される。
* **適用対象カードUIの限定**:
  1. 自分の手札UI
  2. 自分の繰り出しUI
  3. バトルフェーズ中の自分の戦闘カードUI
  4. バトルリザルト画面の自分のカードUI
  * ※ショップや解雇市場のカードには種族倍率補正を適用しない。

### 5.2. 補正対象スタッツの表示色規約
* 種族倍率補正が適用されているスタッツは、**数値部分のみを緑色 (`#22c55e`)** で表示する。
* 数値の左隣にある記号（HP: ❤、攻撃: ⚔、素早さ: ⚡）の色は従来の固有カラーを厳格に維持し、緑色に変更しない。
* 補正対象外のスタッツは、従来の白色数値を維持する。

### 5.3. 種族別補正倍率一覧
* 同種族カード枚数を $N$ とする。
* 端数処理: 計算値は**小数点以下四捨五入**。

| 種族 | 補正対象スタッツ | 補正倍率の計算式 |
| :--- | :--- | :--- |
| **ドワーフ** | HP | $1 + (N - 1) \times 0.10$ |
| **ドラゴン** | 攻撃 | $1 + (N - 1) \times 0.10$ |
| **エルフ** | 素早さ | $1 + (N - 1) \times 0.10$ |
| **オーク** | HP・攻撃 | $1 + (N - 1) \times 0.05$ |
| **ヴァンパイア** | HP・素早さ | $1 + (N - 1) \times 0.05$ |
| **リザードマン** | 攻撃・素早さ | $1 + (N - 1) \times 0.05$ |

## 6. カードプールおよびアセット仕様（全180種類）

属性（6種）× 種族（6種）× レアリティ（5種）＝ **全180種**。
カードマスタデータは `cardsData.js` に集約・管理され、各カードのイラストは `/images/cards/{masterId}.webp` および `/assets/cards/{masterId}.webp` を参照する。

* **イラストアセット推奨解像度**:
  * 幅240px × 高さ180px（4:3、解像度72〜150dpi）のWebP形式でのアセット配置を厳格な推奨とする。
