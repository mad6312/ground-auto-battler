# グラウンド・オートバトラー 正式仕様書 - 02: ショップ・解雇市場仕様

---

## 1. ショップ／解雇市場コンテナ共通レイアウト

準備フェーズにおいて画面上段に配置されるショップおよび解雇市場のベースコンテナは、以下の寸法および緊密な一体化構造を厳格に維持する。

* **独立セクションおよび完全固定サイズ維持（重要要件）**:
  * ショップ／解雇市場UIコンテナ（`#center-board`）は、陳列されているカードの有無（売却済み空き枠、バトル中の全カード非表示時を含む）にかかわらず、**幅840px × 高さ312px の一定固定サイズを厳格に維持**する。
  * 画面遷移やカードの購入・売却・リロールによってコンテナ枠サイズが伸縮することは絶対にない。
* **台形見切れ防止の上部安全余白（改修後正式仕様）**:
  * ショップUI上端に結合された台形ゴールドタブが、ヘッダーや画面上部枠で見切れることを防止するため、コンテナ枠上部に **`margin-top: 26px !important;` の安全余白** を確保する。
* **タブ行と陳列カードの不必要な空白根絶および緊密配置（改修後正式仕様）**:
  * コンテナのフレックス配置は **`justify-content: flex-start !important;`** を適用する（旧仕様の `space-between` による上下端への強制引き離しと、それに伴う約50pxの不必要な空白を完全に根絶）。
  * タブバー（`.market-top-bar`）の高さ（32px）とカード陳列パネル（高さ250px）を直結させ、**タブ行の直下にわずか数pxの美しく緊密な間隔で陳列カードを配置**する。
* **レイアウト構成（縦方向・完全一体化デザイン）**:
  1. **最上部天面中央**: **ショップUIと境界線なく完全一体化した所持ゴールド台形タブ**（高さ約24px、オーバーレイブリッジによりショップ上部枠線との境界線を完全消去）
  2. **上段（タブ＆リロール行）**: 「ショップ」「解雇市場」切り替えタブバー、およびその**右端（同列）に配置されたリロールボタン**
  3. **中段（陳列パネル）**: カード陳列パネル（高さ250px固定、幅100%、余白なしで直結）
* **左右端陳列カードの強調アニメーション見切れ防止規約**:
  * ショップ枠の左端（1枠目）および右端（6枠目）に陳列されたカードに対しても、合成可能な同レア・同種族カードの青色発光パルスアニメーション（`card-synth-highlight`）が枠外で切り落とされることなく100%美しく表示されるよう、コンテナ枠およびカードグリッドに十分なパディングを確保し、`overflow: visible !important;` を適用する。

## 2. 所持ゴールド表示仕様（ショップUI完全一体化台形タブ）

* **ショップフレームとの一体化構造**:
  * 所持ゴールド表示領域は、ショップUIから独立した浮き要素ではなく、**ショップUI天面の中央に直接組み込まれ、境界線（ボーダー）なくひと繋がりに結合された台形タブ（`.shop-gold-trapezoid`）**として描画される。
  * **境界線（ボーダー）の消去**: 台形の下辺とショップUI天面枠線の重なりを解消し、ショップコンテナの立体的なフレームの一部として完全に一体化する。
  * **左右の横長余分スペースの完全排除**: 台形の左右にあった横長のバーや無駄な余白はすべて削除され、所持ゴールドを表示する台形領域そのものがショップUIの上端中央を飾る。
* **台形形状**:
  * 左右の辺が斜めにカットされた台形（上底が短く、下底が長い：`／ 所持ゴールド ＼`）を形成し、ショップ上端と段差なく自然に一体化する。
  * 金貨アイコン（🟡）と現在の所持ゴールド数値（例：`20G`）が鮮やかなゴールドカラー（`#facc15`）で表示される。
* **リアルタイム同期**:
  * ラウンド開始時のゴールド付与、ショップ購入、市場購入、リロール消費、売却獲得のたびに即座に最新値へ更新される。

## 3. ショップ仕様

### 3.1. 基本仕様
* **タブ表示名**: **「ショップ」**
* **陳列枠数**: 6枠（各枠独立抽選）
* **初期選択**: 毎ラウンド開始時、前ラウンドの選択状態にかかわらず必ず「ショップ」タブが選択された状態で初期化される。
* **タブ・陳列カード間隔の短縮**: タブ行と陳列カードの間の縦方向余白は最小限に詰められ、視線移動を減らしたコンパクトで一体感のある配置を維持する。

### 3.2. ラウンド別レアリティ出現率テーブル
各枠は以下の確率に従って独立してレアリティが抽選され、該当レアリティの中からランダムなカードが1枚生成される。

| レアリティ | ラウンド1～4 | ラウンド5以降 |
| :--- | :---: | :---: |
| **コモン** | 45% | 25% |
| **アンコモン** | 25% | 22.5% |
| **レア** | 15% | 20% |
| **エピック** | 10% | 17.5% |
| **レジェンド** | 5% | 15% |
| **合計** | **100%** | **100%** |

### 3.3. リロール機能
* **機能**: 2Gを支払うことで、ロックされていない枠のカードを再抽選して一括で入れ替える。
* **ボタン配置**:
  * **ショップUIの右上、ショップ／解雇市場タブと同じ行の右端（`.shop-reroll-container`）に配置**される。
  * ショップUIのヘッダー行内にすっきりと収容され、陳列カードエリアの視認性を一切邪魔しない。
* **フェーズ制限**: 準備フェーズ中のみ操作可能。準備フェーズ以外（バトルフェーズ中）はボタンが無効化（`disabled`）される。
* **解雇市場タブ表示中の非活性化規約（重要要件）**:
  * **「解雇市場」タブが開いている間は、リロールボタンは恒久的に非活性（グレーアウト・クリック不可）**となる。
  * 再び「ショップ」タブをクリックして切り替えた際は、準備フェーズ中かつ生存プレイヤーであればディレイなく即座に活性化状態へ復帰する。
* **脱落プレイヤーの非活性化規約**: すでにライフが0になり脱落したプレイヤーの画面では、準備フェーズ中であってもリロールボタンは恒久的に非活性状態となる。

### 3.4. ロック機能
* **操作**: ショップ陳列カードを右クリック（タッチ端末ではロングタップ）することで、カード右上に「🔒」バッジが表示され、ロック状態となる。
* **効果**: ロックされたカードはリロール時および次ラウンド開始時に破棄されず、その枠に維持される。再度右クリックすることで解除可能。

### 3.5. 購入操作と手札下部ドロップ判定範囲の拡張
ショップ陳列カードは、ドラッグ＆ドロップにより以下の2通りの方法で購入できる。

1. **手札への購入**:
   * ショップのカードを手札UI（または手札内のカード上）へドラッグ＆ドロップして購入。
   * **購入判定範囲の拡張（重要要件）**:
     **手札UIより下側の画面下端領域にカードをドロップした場合であっても、手札への購入処理が確実に成立**する。ドロップ位置がわずかに下へずれたことによる購入の不発を完全に排除する。
2. **出撃スロットへの直接購入・配置**:
   * ショップのカードを出撃スロット（1～3）へ直接ドラッグ＆ドロップすることで、購入と同時にそのスロットへ即座に配置される。
3. **ゴールド不足時の挙動**:
   * 所持ゴールドがカード購入額に満たない場合、購入・配置は実行されず、「ゴールドが足りません」というトースト通知が表示される。
4. **売却済み表示**:
   * 購入された枠は、破線枠の「売却済み」表示となり、次回転（リロールまたは次ラウンド）まで空き枠として維持される。

### 3.6. 購入価格の表示
* **カードUI内部には一切配置しない**。
* 陳列されている各カードの**直下（外側）に中央揃え**で、金貨アイコン付きピル型バッジ（`🟡 2G` 等）として美しく表示される。空き枠時は非表示となり高さ20pxの空間が維持される。

## 4. 解雇市場仕様

### 4.1. 基本仕様とタブ名称
* **タブ表示名**:
  * 第1ラウンド: **`解雇市場 (R2～)`**
  * 第2ラウンド以降: **`解雇市場(N)`**（$N$ は自分の解雇市場に現在陳列されているカード枚数。リアルタイム更新。バトルフェーズ移行時は **`解雇市場(0)`** となる）
* **第1ラウンドの制限**:
  * 第1ラウンド中は利用不可。タブはグレーアウトされ、マウスオーバー時は禁止マークカーソル (`not-allowed`) となる。クリックしても何も起きない。
* **バトルフェーズ中の非表示**:
  * バトルフェーズが開始されると、解雇市場に陳列されているカードはすべて非表示となる（セクション枠自体は縮小せず幅840px・高312pxの固定サイズを維持）。

### 4.2. 陳列ルール
* **供給源**: 前ラウンド中に他プレイヤーが解雇（売却）したカードが陳列される。
* **自己出品の除外**: 自分が解雇したカードは、自分の解雇市場には陳列されない（他プレイヤーの市場にのみ陳列される）。
* **ラウンド跨ぎ消滅**: 陳列されたカードは次ラウンドには引き継がれず、準備フェーズ終了とともに消滅する（ロック機能は不可）。
* **陳列上限とスクロール**: 7枚以上陳列された場合は、枠内で縦スクロール（`.market-scroll-grid`）して全カードを閲覧可能とする。

### 4.3. 購入ルール・計算式・解バッジ付与
* **購入価格計算式**:
  解雇市場に陳列されるカードの購入価格は、以下の計算式に従う（カード直下に中央揃えで表示）。

$$
\text{解雇市場での購入価格} = \left\lfloor \frac{\text{ショップでの購入額} \times \text{★バッジの数値}}{2} \right\rfloor
$$

* **購入操作**:
  * 手札UI、手札内のカード上、手札UIより下側の領域、または出撃スロットへドラッグ＆ドロップすることで購入可能。
  * 所持金不足時は購入されず「ゴールドが足りません」のトーストが表示される。
* **他者への影響なし（独立在庫）**:
  * あるプレイヤーが解雇市場のカードを購入しても、他プレイヤーの解雇市場の陳列状況には影響しない。
  * 購入したプレイヤーの画面からは即座にそのカードが消滅し、同じカードを複数回購入することはできない。
* **「解バッジ」の付与**:
  * 解雇市場から購入されたカードには、カードイラスト右下に **「解」** バッジが付与される。
  * 「解」バッジにホバーすると吹き出し型ポップアップで「解雇者：〇〇」が表示される。
* **★バッジの引き継ぎ**:
  * 解雇された時点の **★バッジの数値をそのまま引き継ぐ**（★1へリセットされない）。
