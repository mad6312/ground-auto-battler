# グラウンド・オートバトラー 正式仕様書 - 02: 準備フェーズ仕様

---

## 1. 準備フェーズの開始・ラウンド初期化処理

準備フェーズは全プレイヤーが同時にリアルタイム進行する。
各ラウンドの開始時、以下の処理が自動的かつ厳格な順序で実行される。

### 1.1. 出撃スロットの手札全回収
* 各ラウンド開始時、繰り出しUI（出撃スロット1～3）に配置されているカードは、**すべて手札UIへ自動的に戻される**。

### 1.2. ショップタブの初期選択
* 前ラウンドのタブ選択状態にかかわらず、毎ラウンド開始時は必ず **「ショップ」タブが初期選択** された状態にリセットされる。

### 1.3. 生存プレイヤーへのカード追加配布
脱落していない全生存プレイヤーの手札へ、ランダムなカードが1枚新しく追加配布される。
* **ラウンド別レアリティ解放条件（厳格に維持）**:
  * 第1ラウンド: コモンのみ
  * 第2ラウンド: アンコモン解放
  * 第3ラウンド: レア解放
  * 第4ラウンド: エピック解放
  * 第5ラウンド以降: レジェンド解放
* **解放済みレアリティ間の抽選比率**:
  * 各ラウンドで解放済みのレアリティのみを対象とし、後述「3. ショップ仕様」のラウンド別出現率（R1～4 / R5以降）の比率に従って抽選される。未解放のレアリティが配布されることは絶対にない。

### 1.4. 各ラウンド開始時ポップアップ演出と配布の順序規約
ラウンド開始時、画面中央に以下の2行構成のポップアップ演出が表示される。

> ラウンド〇  
> 残プレイヤー:△  
> （例：`ラウンド2` / `残プレイヤー:5`）

* **順序の厳格な保証**:
  1. 「ラウンド〇」ポップアップ演出を開始する。
  2. ポップアップ演出が終了するまで、**配布カードは手札UIに絶対に表示しない**。
  3. ポップアップ演出（約1.6秒）が正常に終了した後、配布カードが画面外（画面中央上部）から手札UI内の所定位置へ滑らかに飛翔するアニメーションを再生する。
  4. アニメーション終了後、カードが手札内の正しい整列位置に収まる。

### 1.5. ラウンド開始時のゴールド付与
毎ラウンドの準備フェーズ開始時、各生存プレイヤーへ以下のゴールドが付与される。
* **ラウンド1**: 付与なし
* **ラウンド2～4**: **10G**
* **ラウンド5以降**: **15G**

## 2. 手札UIのカード自動整列順序

手札UIに表示されるカードは、常に以下の優先順位に従って**すべて左から右へ自動整列**される。カードの追加・購入・移動・合成が行われるたびに、この並び順が一貫して適用される。

| 優先順位 | 分類 | 左から右への並び順 |
| :---: | :--- | :--- |
| **第1優先** | **レアリティ** | コモン ➔ アンコモン ➔ レア ➔ エピック ➔ レジェンド |
| **第2優先** | **種族** | ドワーフ ➔ ドラゴン ➔ エルフ ➔ オーク ➔ ヴァンパイア ➔ リザードマン |
| **第3優先** | **属性** | 火 ➔ 氷 ➔ 風 ➔ 雷 ➔ 水 ➔ 地 |

## 3. ショップ仕様

* **タブ表示名**: **「ショップ」**
* **陳列枠数**: 6枠（各枠独立抽選）
* **ラウンド別レアリティ出現率**:
  ショップの陳列枠、およびリロール時の抽選には、ラウンド数に応じた以下の出現率が適用される。

| レアリティ | ラウンド1～4 | ラウンド5以降 |
| :--- | :---: | :---: |
| **コモン** | 45% | 25% |
| **アンコモン** | 25% | 22.5% |
| **レア** | 15% | 20% |
| **エピック** | 10% | 17.5% |
| **レジェンド** | 5% | 15% |
| **合計** | **100%** | **100%** |

* **リロール**: 2Gを支払うことで、ロックされていない枠を再抽選して入れ替える。
  * **フェーズ制限**: 準備フェーズ中のみ操作可能。準備フェーズ以外（バトル中）はボタンがグレーアウトされ、リロール操作は無効化される。
* **ロック機能**: カードを右クリックすることでロック状態（🔒）を切り替えられる。ロック中のカードはリロール時および次ラウンド開始時に維持される。
* **購入操作**:
  1. **手札へ購入**: ショップのカードを手札UIへドラッグ＆ドロップ。
  2. **出撃スロットへ直接配置**: ショップのカードを出撃スロット（1～3）へ直接ドラッグ＆ドロップして購入・即時配置。配置先に既存カードがある場合は、既存カードを手札に残した上で配置される。
* **購入額の表示**: ショップおよび解雇市場に陳列中のカードにのみ表示。

## 4. 解雇市場仕様

* **タブ表示名**:
  * 第1ラウンド: **`解雇市場 (R2～)`**
  * 第2ラウンド以降: **`解雇市場(N)`**（$N$ は自分の解雇市場に現在陳列されているカード枚数。リアルタイム更新）
* **第1ラウンドの制限**: 利用不可。タブはグレーアウトされ、マウスオーバー時は操作不可を示す**禁止マークのカーソル (`not-allowed`)** となる。
* **陳列ルール**:
  * 前ラウンド中に他プレイヤーが解雇（売却）したカードが陳列される。
  * 自分が解雇したカードは、自分の解雇市場には陳列されない。
  * 陳列されたカードは次ラウンドには引き継がれず消滅する（ロック不可）。
* **購入ルール**:
  * 購入価格は **合計スタッツの 1/10**（端数切り捨て）。
  * 誰かが購入しても、他プレイヤーの解雇市場の陳列状況には影響しない。
  * 購入したプレイヤーの画面からは即座にそのカードが消滅し、同じカードを複数回購入することはできない。
  * 購入されたカードには **「解バッジ」** が付与される。
  * 解雇された時点の **★バッジの数値をそのまま引き継ぐ**。

## 5. カードの合成仕様

* **合成条件**: **同レアリティ** かつ **同種族** のカード同士のみ合成可能。
* **合成操作**:
  * 手札にある合成元カードに対して、以下の領域にあるカードをドラッグ＆ドロップする。
    1. 手札内の別カード
    2. ショップの陳列カード（購入費用を消費）
    3. 解雇市場の陳列カード（購入費用を消費）
  * ※繰り出しUIに配置されているカードを手札カードへドラッグ＆ドロップした場合は、合成ではなく**カードの入れ替え**が行われる。
* **合成結果**:
  * 各スタッツ（HP, 攻撃, 素早さ）が合算される。
  * **★バッジの数値が合算される**（例：★1 ＋ ★1 ＝ ★2、★1 ＋ ★2 ＝ ★3）。
  * 素材カードは消滅する（出撃スロット内の素材が合成された場合も、複製されることなく確実に消滅する）。
  * 合成元または素材に「解バッジ」があっても、**合成後のカードには「解バッジ」を引き継がない**（通常のカードとなる）。
* **合成関連演出**:
  * **合成可能カードの強調表示**: ショップ・市場・繰り出しUI・手札のカードをホバーまたはドラッグした際、自身を除く【レアリティと種族が一致するカード】すべてに青色の発光アニメーションを表示する。
  * **合成成立アニメーション**: 合成が成功した際、合成元カードがゴールドに拡大発光するポップアニメーションを再生する。

---

## 6. カードの解雇（売却）仕様

* **UI表示名**: **「🗑 解雇エリア (売却)」**
* 手札または繰り出しUIのカードを解雇エリアへドラッグ＆ドロップすることでカードを売却しゴールドを獲得する。
* **獲得ゴールドの計算式**（合計スタッツは使用しない）:
  * **解バッジなし**: $\lfloor \text{ショップ購入額} \times \text{★バッジの数値} / 2 \rfloor$
  * **解バッジあり**: $\lfloor \text{ショップ購入額} \times \text{★バッジの数値} / 4 \rfloor$
  * ※計算結果の小数点以下は切り捨て。購入額はレアリティに応じた通常購入額（コモン:2G, アンコモン:4G, レア:6G, エピック:8G, レジェンド:10G）。
* 解雇されたカードは、解雇時点の★バッジ数値を保持したまま次ラウンドの他プレイヤーの解雇市場へ送られる。

## 7. 出撃スロットとカード移動操作

* 手札から最大3枚までを出撃スロット（番号1～3）にドラッグ＆ドロップで配置する。
* **手札カードの右クリックによる自動配置**:
  * 手札カードを右クリックした際、出撃スロットの最も手前の空き枠（1番 ➔ 2番 ➔ 3番）へ自動的に配置される（1～3番がすべて埋まっている場合は何も実行しない）。
* **スロットカードの右クリック解除**:
  * 出撃スロットのカードを右クリックすると、即座に配置が解除され手札に戻る。
* **手札追加・移動時の滑らかなアニメーション**:
  * ショップや市場からの購入、出撃スロットからの解除・ドロップ戻し時、**カードをドロップしたマウス座標から手札UI内の本来の整列位置まで、カードが途切れず滑らかに移動するアニメーション**が再生される（瞬間移動や一時消失は発生しない）。
* **待機中における操作権限（正式仕様）**:
  * 「完了」ボタンを押して待機状態（待機ランプ点灯・アナウンス表示中）になった後でも、バトルフェーズが開始される前であれば、**カードの購入・リロール・合成・売却・出撃配置の変更および解除がすべて正常に実行可能であり、これは意図された正式な仕様である**。
  * 待機中に変更された出撃構成や所持カードは、サーバー側へリアルタイムで正常に同期・保存される。

## 8. 準備完了フローと確認モーダル

プレイヤーが「完了」ボタンをクリックした際、以下の優先度でチェックが行われる。

1. **脱落プレイヤーの操作無効化**:
   * すでにライフが0になり脱落したプレイヤーは、「完了」ボタンが恒久的に非活性（グレーアウト）となり、クリックしても一切の準備完了処理は受け付けられない。
2. **手札7枚以上の場合**:
   * 手札が6枚以下になるまで売却するカードを選択させるモーダルを表示する。
   * **モーダル表示中のルール**: 合成候補の強調発光アニメーションは無効化される。
   * **自動待機移行**: プレイヤーがカードを解雇して手札が6枚になった時点で、**改めて完了ボタンを押すことなく自動的に待機状態へ移行**する。
3. **繰り出しカードが0枚の場合（手札0枚時も含む）**:
   * 手札0枚の専用モーダルは廃止され、以下の確認モーダルに統一して表示される。
   > 繰り出すカードを選択していません。  
   > 本当に完了しますか？  
   > [はい] / [いいえ]
4. **準備完了後**:
   * 「完了」ボタンは非活性（グレーアウト）となる。
   * 画面上部に **「全員の準備完了を待っています...」** のアナウンスメッセージが表示され、バトルフェーズが開始されるまで維持される。
   * 自身の待機状態ランプが点灯する（※前項7の通り、待機中でも購入・リロール・合成・配置変更は継続して実行可能）。
   * 全生存プレイヤーが準備完了になると、自動的にバトルフェーズへ移行する。

## 9. 操作時間制限に関する方針

* **制限時間なしの原則（現行仕様）**:
  * **現時点においては、準備フェーズおよび各操作に制限時間を設ける予定はない**。全生存プレイヤーが自発的に「完了」ボタンを押し、全員の準備が整ったタイミングでバトルフェーズへ移行する。
* **今後の実装検討項目**:
  * プレイヤー間のテンポ維持や放置対策等を目的とした操作制限時間（タイマー機能）の導入については、**今後のアップデートにおける実装検討項目**として位置付ける。

## 10. 他プレイヤー枠の操作制限と前ラウンド情報

### 10.1. 脱落プレイヤー枠の操作不可
すでにライフが0になり脱落したプレイヤーの枠は、マウスオーバー時にマウスポインターが**禁止マーク (`not-allowed`)** に変化し、クリックしてもモーダル表示や画面遷移等の処理は一切行われない。

### 10.2. 「〇〇の前ラウンド情報」モーダル
生存プレイヤーの枠（カードプレート本体）をクリックすることで、前ラウンドの出撃情報モーダルを開くことができる。
* **表示内容**: 前ラウンドに繰り出したカード順および控えカード。
* **弱点属性の表示**: 各カードの上部に **「弱点：〇」**（〇には弱点属性バッジ）が表示される。
* **相手種族補正の完全再現**: 前ラウンド終了時点の相手自身のカード構成に基づく種族補正スタッツを正確に表示し、**補正対象スタッツの数値部分のみを緑色**（記号色は維持、端数は四捨五入）で表示する。

## 11. 待機状態ランプの状態遷移規約

待機状態ランプは、以下の通り全プレイヤーの画面にリアルタイム同期される。

1. **準備フェーズ開始時**: 全員 **消灯**
2. **準備完了時**: 「完了」ボタンを押した生存プレイヤーが **点灯**（※購入・リロール・合成・配置変更は引き続き可能）
3. **バトルフェーズ開始時**: 全員 **消灯**
4. **バトルリザルト確認後**: 「次へ」ボタンを押したプレイヤーが **点灯**（※他プレイヤー枠に「観戦」ボタンが即座に表示・維持される）
5. **次ラウンド準備フェーズ移行時**: 全員 **消灯**
