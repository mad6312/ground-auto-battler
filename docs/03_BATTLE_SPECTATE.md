# グラウンド・オートバトラー 正式仕様書 - 03: バトルフェーズ・観戦仕様

---

## 1. マッチング仕様

### 1.1. マッチングタイミングと対戦相手表示
対戦相手のマッチング処理は、**各ラウンドの開始時（準備フェーズ開始時）** に行われる。
* 画面左上の「ラウンド:〇」の右隣に、**「次の対戦相手:〇〇」** が準備フェーズ中から表示される。
* **表示タイミングの制御**: バトルリザルト画面で「次へ」をクリックして待機状態になった際は非表示となり、次ラウンド開始時に再び新マッチングが表示される。

### 1.2. 過去の対戦履歴に基づく再マッチング回避
マッチングを作成する際、そのゲーム中に**すでに対戦したことがある相手との再マッチングを可能な限り回避**する。
* 各プレイヤーの対戦履歴を参照し、未対戦のプレイヤーを最優先でペアリングする。
* 参加人数の都合等で未対戦相手がいない場合に限り、既存対戦相手とのマッチングを許容する。

### 1.3. 「(影)」の選定と対戦履歴
生存プレイヤー数が奇数の場合、余ったプレイヤーに対戦相手のコピー「(影)」を割り当てる。
* 「(影)」を選定する際も対戦履歴が考慮され、**まだ対戦したことのないプレイヤーに対応する「(影)」が優先的に割り当てられる**。
* コピーが敗北しても、コピー元の本体プレイヤーのライフは減少しない。

### 1.4. 準備フェーズ中の切断と再マッチング
準備フェーズ中に対戦相手が切断した場合、自動的に他プレイヤーの「(影)」と即座に再マッチングが行われ、「次の対戦相手:〇〇」の表示もリアルタイムで更新される。

## 2. バトルフェーズ開始時の画面・カード制御

### 2.1. 手札超過カードの自動解雇
準備フェーズで7枚以上の手札が残ったままバトルフェーズへ移行した場合、**バトル開始時**に手札が6枚になるまで控えカードからランダムに自動解雇（売却）される。
* 出撃スロット配置カードは対象外。
* ショップ購入額・★バッジ数値・解バッジに応じた売却ゴールドが即座に所持金へ加算される。

### 2.2. ショップおよび解雇市場の非表示化
各ラウンドのバトルフェーズ開始時、ショップおよび解雇市場に陳列されているカード（「売却済み」表示を含む）はすべて画面上から非表示となる。
* 準備フェーズ以外でのリロール操作はボタンがグレーアウトされ無効化される。
* 次ラウンドの準備フェーズ開始時に再びカードが正常に陳列される。

## 3. バトル画面レイアウトと演出

### 3.1. 画面レイアウトの完全固定化
* **自分自身の左側固定**: 先攻・後攻・マッチングによらず、**自分自身のカードが必ず画面左側**、対戦相手のカードが必ず画面右側に配置される。
* **プレイヤー情報・インジケーターの分離固定**: プレイヤー名および残り出撃枚数インジケーターは、カードのアニメーションスロットと完全に分離され、カードが攻撃・被弾で動いても所定位置に固定される。

### 3.2. 残り出撃カード枚数の表示（●〇インジケーター）
プレイヤー名の下に、出撃カードの残数をリアルタイムに「●」「〇」で表示する。
* 3枚出撃時: `●●●` ➔ 1枚倒されると `●●〇` ➔ `●〇〇` ➔ `〇〇〇`
* 2枚出撃時: `●●` ➔ `●〇` ➔ `〇〇`
* 1枚出撃時: `●` ➔ `〇`

### 3.3. 戦闘演出と残HPリアルタイム反映
1. **攻撃動作**: 相手方向へ踏み込むアニメーション。
2. **被弾動作**: 揺れ動きと赤色フラッシュ。
3. **回避動作**: 身を引く回避アニメーションと「MISS」のポップアップ。
4. **ダメージポップアップ**:
   * 通常ヒット: 白色
   * 弱点攻撃（2.0倍）: 橙赤色
   * 耐性軽減（0.5倍）: 水色
   * 会心の一撃（1.5倍）: 金色
5. **残HPのリアルタイム更新**:
   * ダメージを受けるたびに、カードUI上のHP数値が最新の残HPへ即座に更新される。
   * **種族倍率補正の表示色維持**: 種族倍率補正が適用されているカードは、HP数値が減少・変化しても**数値部分のみ緑色 (`#22c55e`)** を厳格に維持し、HP記号（❤）の色は従来の赤色を維持する。
   * 補正対象外カードは従来の白色数値を維持する。
6. **HP0消滅と復活見え防止**:
   * HPが0になったカードは、消滅アニメーションとともに画面から完全に取り除かれる。
   * 新カードが繰り出されるまでスロットは空のまま維持され、古いカードが再表示・復活して見えることはない。
   * 新カードが出撃した直後に一撃で倒された場合も、出撃・表示・攻撃・消滅の順序が保証される。
7. **ログの最新行自動スクロール**:
   新しいログが追加されるたび、ログ表示枠は常に最新行へ自動スクロールされる。

## 4. 戦闘シミュレーション計算

戦闘は完全自動で進行する。

* **攻撃順**:
  * 場のカード同士の素早さを比較し、**素早さが高いカードから先攻**。
  * 素早さが同値の場合はランダム（50%）。
  * カード撃破により新たなカードが繰り出された際は、素早さを再度比較して先攻を決定する。
* **命中率とダメージ計算式**:
  1. 基本ダメージ ＝ 攻撃側カードの攻撃スタッツ
  2. 命中判定 ＝ **命中率 $\left(100 - \frac{25}{3}\right)\% \approx 91.67\%$**（外れた場合は 0 ダメージ）
  3. クリティカル判定 ＝ 命中時、**1/6 の確率で発生**（ダメージ 1.5倍）
  4. 属性相性倍率 ＝ 弱点 2.0倍、耐性 0.5倍、等倍 1.0倍
  5. **端数処理**: 各種補正を適用した後の最終ダメージは **小数点以下四捨五入** とする。
  6. **最低ダメージ保証**:
     * 通常ヒット時: 四捨五入後の最終ダメージは **最低でも 1**
     * クリティカル発生時: 四捨五入後の最終ダメージは **最低でも 2**
  7. 計算式まとめ:
     * 通常ヒット時: $\max\left(1, \operatorname{round}(\text{基本ダメージ} \times \text{属性倍率})\right)$
     * クリティカル時: $\max\left(2, \operatorname{round}(\text{基本ダメージ} \times \text{属性倍率} \times 1.5)\right)$
* **勝敗**:
  * 出撃カードが全滅した側が敗北（ライフ -1）。
  * 戦闘で減少したHPは、次ラウンド開始時に全回復する。

## 5. バトルリザルト仕様

対戦終了後、バトルリザルトモーダルが表示される。

### 5.1. 戦闘ダメージ詳細の3列構成と遺影表現
左側に「戦闘ダメージ詳細」、右側に「バトル経過ログ」を独立して配置する。
* **3列ヘッダー構成**:
  テーブルの列構成は左から **「自分」「相手」「与えた合計ダメージ」** とする。
* **全交戦カード組み合わせの1行表示**:
  そのバトル中に戦闘を行ったすべてのカードの組み合わせについて、1行ずつ表示する。
  * **左列（自分）**: 自分側の該当カードUIを表示。
  * **中央列（相手）**: 相手側の該当カードUIを表示。
  * **右列（与えた合計ダメージ）**: その2枚同士の戦闘で、自分側のカードが相手側のカードに与えた合計ダメージを**中央揃え**で表示。
* **先にHP0になったカードの遺影表現**:
  各カード同士の戦闘において、**先にHPが0になったカードのUIに遺影のような視覚表現（モノクロ・コントラスト強調・専用黒枠リボン）を適用**する。
  * 自分のカードが先にHP0になった場合: 左列の自分カードUIが遺影表示となる。
  * 相手のカードが先にHP0になった場合: 中央列の相手カードUIが遺影表示となる。
* **バトル経過ログの常時展開**: 経過ログは最初から常に展開されて表示される。
* **観戦時の勝敗文言**: 他プレイヤーのバトルを観戦していた場合、勝敗メッセージは **「〇〇がバトルに勝利しました！」** と表示される。

### 5.2. 「次へ」ボタン押下フロー
* モーダルが閉じ、**自身の待機ランプが即座に点灯**する（全プレイヤーの画面へリアルタイム同期）。
* 画面上部に **「全員のバトル終了を待っています...」** のアナウンスが表示される。
* **観戦ボタンの即時表示と維持**: 「次へ」をクリックしたプレイヤーに対して、**全生存プレイヤー枠に「観戦」ボタンが即座に表示され、新ラウンドへ移行するまで安定して維持**される。
* ※すでに優勝者が決定している場合は、待機処理を行わず即座に最終リザルト画面へ遷移する。

## 6. 観戦機能および観戦予約仕様

### 6.1. 非脱落プレイヤーの観戦
バトルリザルト画面で「次へ」をクリックした非脱落プレイヤーは、プレイヤー枠に即時表示された **「観戦」ボタン** をクリックしてリアルタイム観戦画面へ移行できる（プレート本体クリックは前ラウンド情報表示）。

### 6.2. 脱落プレイヤーの観戦予約機能
脱落プレイヤーの画面では、準備フェーズ中に対戦相手枠に **「観戦予約」ボタン** が表示される。
* **予約トグル**:
  * 「観戦予約」クリックで予約が有効になり、ボタンが **「予約解除」** に切り替わる。
  * 「予約解除」クリックで解除される。
  * 別のプレイヤーをクリックした場合は以前の予約が自動解除され、新しいプレイヤーに切り替わる（有効な予約は常に1名のみ）。
* **自動遷移**: バトルフェーズが開始されると、予約していたプレイヤーのバトル観戦画面へ自動遷移する。
* **予約の継続**: 自動遷移で観戦した場合、**次ラウンド開始時もそのプレイヤーの「観戦予約」が有効な状態が引き継がれる**。
* **ラウンド跨ぎの観戦維持**: 観戦中に次ラウンドへ移行した場合も、観戦画面を強制中断せず継続表示する。
